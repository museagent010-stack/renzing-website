# Renzing Website

German-first sample website for Renzing Sanitär, Heizung & Badsanierung, built from the Deep Research package (Renzing GPT).

## Deploy on Cloudflare Pages

- Framework preset: None (static HTML)
- Build command: (none)
- Build output directory: `/` (repo root)
- `index.html` is the site entry point; `_headers` sets the HTML content type.
- Custom domain: `renzing.cleancodelabz.com`

## Notes

- Contact details are placeholders per the research guardrails (city, address, phone, reviews unconfirmed).
- Booking uses a prefilled Google Calendar event until Renzing shares a real Google Appointment Schedule link.
